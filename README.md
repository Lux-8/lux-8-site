# Сайт команды разработчиков Lux-8

Официальный веб-сайт команды **Lux-8** с информацией о наших проектах, направлениях разработки, стеке технологий и контактах.

## О команде
**Lux-8** — команда молодых разработчиков, создающая веб-сервисы, Telegram-ботов, системные утилиты и проекты с использованием искусственного интеллекта.
(**В данный момент в команде 1 разработчик**)

## Стек технологий сайта
* **HTML5** — семантическая структура страниц (`index.html`).
* **CSS3** — адаптивная вёрстка и визуальное оформление (`style.css`).
* **SVG** — векторная графика, логотип и фавикон команды (`Lux-8.svg`, `Lux-8-favicon.svg`).
